LOGIN & ACTIVITY — DEPLOYMENT NOTE

This offline HTML prototype does not provide secure user accounts, verified email/password login, reliable cross-device chapter/download analytics, or secure storage of phone numbers. Do not collect or store passwords in this page. For those features, connect a server-side authentication provider and database with access controls and a clear privacy notice.

IMPORTANT

For the Admin page and student site to share updates, upload both files to the same website origin and open them in the same browser. Browser storage does not sync between devices. A separate URL is not the same as secure access control; before publishing, add authentication and a shared database such as Supabase/Firebase.
